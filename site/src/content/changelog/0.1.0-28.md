### The safety net

- **Recently Deleted.** Deletion in LevelSelect has always been soft under the hood; now the way back is a screen. Settings → Your data → Recently Deleted lists every game, playthrough, and collection you've deleted, each with a one-tap Restore. Nothing auto-purges — what you deleted waits for you, however long that takes.
- **Delete Forever is the only hard delete in the app**, and it lives here, behind the app's only double-confirmation. Everything else is always recoverable.

### The export comes home

- **Import LevelSelect export.** The readable JSON file that Export writes is no longer a one-way record — pick it in Settings → Your data and the app restores whatever the file has that your library doesn't: games, playthroughs, sessions, runs, tracker progress, completions, videos, maps and markers, collections.
- **It never touches what's already here.** Import is additive by id — a record you still have is skipped, edits you've made since the export survive untouched, and running the same import twice changes nothing. You see exactly what will be restored, and what's already present, before anything happens.
- **Together, that closes the loop:** export is now a real backup, not just a record. iCloud keeps devices in sync; the export file is the copy you keep.

### Legible at every size

- **The largest text sizes now reflow instead of clipping.** At accessibility text sizes the game page stacks its cover above the details, Stats folds its overview into a 2×2 grid, and buttons that used to truncate ("P…") show their symbol and speak their word.
- **VoiceOver says what things are.** A library row reads as one sentence — name, status, platform, rating. A tracker tick says what it ticks and whether it's done. The play heatmap summarizes itself instead of reciting 105 squares. Missable warnings, count steppers, and remove buttons all have names now.
- **Reduce Motion is honored everywhere** — banners fade instead of sliding, joining the cover shine and timer pulse that already knew how to hold still.
