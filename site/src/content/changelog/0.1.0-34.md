Library holds your games and how you relate to them, and there are three ways to say that: the **status** of a game, the **system** it's on, and how you **own** it. Only two were ever on screen. Ownership was a line in a menu, which is a way of saying it did not really count.

So all three are visible now, and none of them ranks above the others.

## Ownership is something you browse

A row of chips above the shelf: physical, digital, emulated, previously owned, each with a count, followed by your tags. Tap one to narrow, tap again to widen.

The point is what happens when you combine them. *"Genesis, the ones I emulate"* is two taps, and the chips stay lit so you can see why the shelf went quiet — where before you'd get four games and a filled-in filter icon explaining nothing.

If a lot of your library has no ownership recorded, a dashed **No ownership set** chip says how many. Tap it and you have exactly the games that need fixing; long-press any cover to set it without opening the game.

## Consoles are libraries

Tapping a system used to open a bare grid. On a console with fifty games that is a wall.

It now carries the same machinery as Library itself — search, filters, sort, all three layouts — because that is what it is: that console's shelf, seen on its own.

## A game can be yours on more than one console

It couldn't be, before. Ownership lived in a single slot, so marking a second console quietly unmarked the first, and owning something on both Switch and PC was simply unsayable.

Now it is a set. The consoles you own a game on sort to the front of its platform list, the systems shelf counts a game under each of them, and a game bought twice appears on both consoles' pages — one game seen from two shelves.

## The wishlist knows what's out

Games you want now sort into **Coming soon**, **No date yet**, and **Out now**.

The middle one is the interesting one. A game can be announced without being given a date — the Ocarina of Time remake has been announced for "late 2026" and nothing more — and that is a different kind of waiting from one you could buy this afternoon. It empties itself into Coming soon the moment a day is announced.

Dates behave themselves too. They keep the day they actually have, and refuse to invent one they don't: a game IGDB knows only the year for says *2026*, quietly, rather than claiming a launch date nobody has given.

If you use Deku Deals, its list stops being a stranger. Rows say **In your library** or **On your wishlist**, and it will not offer to add a game you already have.

## A menu bar, on Mac and iPad

The Mac had no menus worth the name. It has File, Edit and View now — add a game, import, search, sort, layouts, and ⌘1–⌘4 for the tabs — and the same block serves iPad, where iPadOS draws a real menu bar from it.

## Fixes

**Sessions were being measured by the wrong clock.** The editor showed wall-clock time rather than time played, so a timer left running overnight read as twelve hours — and saving would have written those twelve hours into your library. It now agrees with every other number in the app.

Every session is reachable, too. A game with more than five has **See all**, filterable to a single playthrough; before, older sessions counted toward your totals while being impossible to see or correct.

Elsewhere: the system filter listed every platform a game was *released* on rather than the one you own it on. Home's header showed whichever game came first alphabetically instead of the one you last played, and a game you finished now counts as part of your week — with a **Recently Beaten** row for the last month.
