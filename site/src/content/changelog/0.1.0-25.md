### A tracker doesn't have to arrive all at once

- **Ask what a game should even be tracked by.** "Suggest Categories" comes back in seconds with the sets that game is actually divided into — Shrines, Divine Beasts, Korok Seeds — as placeholders you can accept, rename or throw away before anything is generated.
- **Fill one category at a time.** Each placeholder has its own Generate button, and filling one leaves every other category exactly as it is. A big game no longer means one long generation that can fail entirely and leave you with nothing.
- **Long lists actually arrive.** A hundred-plus shrines used to run past the time limit and come back as though the generator had never heard of the game. Long categories now come back plainly — name and location, no padding — because a list that arrives beats a richer one that doesn't.
- **Nine hundred Korok seeds are one counter, not nine hundred rows.** Sets too large to tick individually are tracked as a running total, and the placeholder says so before you generate it rather than promising rows it was never going to produce.
- **Categories you've finished rise to the top**, planned ones sink, and you can pin the ones you care about or hide the ones you haven't started.
- **A tracker can be thrown away**, not only overwritten — and removing one tells you what progress goes with it first.

### RetroAchievements

- **Import the real achievement list.** For a game RetroAchievements covers, this is the authored list the emulator itself pops up against — not a generated approximation. It arrives in a second, with the points each achievement is worth.
- **Connect your own account and sync what you've earned.** Unlocks land in a dedicated RetroAchievements playthrough, kept separate from a playthrough you're timing by hand.
- **A sync can only ever add.** Nothing it doesn't know about gets un-ticked — it has no idea you played the cartridge on real hardware last week, so silence from it is not evidence of anything.
- **Your API key never touches our server.** Those requests go straight from your device to RetroAchievements.
- **Offered where it applies.** On a game you've marked emulated, or on a console RetroAchievements covers, the import is a button rather than something buried in a menu.
- **An imported set survives regeneration.** Generating a tracker over a game that already has an achievement list now keeps the list and adds the generated categories beside it.

### Collections

- **Start from a question, not a blank name field.** Templates ask something specific — the ones you keep meaning to get back to, the ones you've owned for years and will probably never open — and several fill themselves in from your own library.
- **Pick from cover art.** Choosing what goes in a collection is a grid of covers with a running count, so a collection meant to hold ten doesn't quietly become thirty.

### Knowing more about a game

- **Critic scores and time-to-beat**, where enough people have actually said so — a score built from two reviews isn't a score, so it isn't shown as one. Both can be turned off entirely if you'd rather judge for yourself.
- **Connected games.** Remasters, collections and sequels of the game you're looking at, without the bad matches a plain name search produces.
- **Every field is a way into your library.** Tapping a developer, publisher, genre, year or perspective shows everything else you own by that measure.
- **Personal collections show on the game page**, distinct from a purchased bundle the game happens to belong to.

### Elsewhere

- **Running timers live on the first screen**, with pause and stop, instead of only inside the game you started them from.
- **An "ongoing" status** for games that are never really finished, and Home shelves you can hide.
- **Prerequisites are visible.** A tracker can show what isn't reachable yet, and warn you before ticking something that closes another objective off for good.
- **The platform shown is the one you picked**, not the one the app would have preferred.
- **Only the category you pressed spins**, and a failure you watched happen isn't announced to you again on the next screen.
- **Three cramped views now grow with your text size** instead of clipping at the larger accessibility sizes.
