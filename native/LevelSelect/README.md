# LevelSelect (native)

Multiplatform SwiftUI + SwiftData app (iOS 26 / iPadOS 26 / macOS 26), Swift 6.
Native conversion of the LevelSelect web app. See `../DOMAIN-MODEL.md` for the
data model and `../../dev` Obsidian notes (LevelSelect native conversion roadmap)
for the plan.

## Layout
```
LevelSelect/
  App/            LevelSelectApp.swift  (@main, ModelContainer)
  Domain/         Enums.swift
  Persistence/    Schema.swift (VersionedSchema V1 + MigrationPlan + container)
    Models/       12 @Model types (Game, Playthrough, Session, …)
  UI/             RootView.swift (placeholder Library shell)
```

## Build
The project file is generated by xcodegen (not committed). Regenerate after
changing `project.yml` or adding files:
```sh
cd native/LevelSelect
xcodegen generate
```
`xcode-select` points at the Command Line Tools, so build against Xcode.app
explicitly (same pattern as stonewall-project-planner):
```sh
env DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  xcodebuild -project LevelSelect.xcodeproj -scheme LevelSelect \
  -destination 'platform=macOS' build
```
The macOS build is the fast verification signal. There is no unit-test target yet.
